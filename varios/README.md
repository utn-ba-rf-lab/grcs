# grcs/varios
En esta carpeta encontrará diagramas para demostraciones o realizar tareas específicas

## wav_to_raw.grc

Genera un archivo con muestras complejas en formato float 32 (.raw) a partir de un archivo .wav

## Factor_de_cresta.grc

Determina el factor de cresta, valores máximos y RMS cada intervalo de un segundo. La entrada es un archivo .wav en 44100 SpS
